# Contributing

Contributions are welcome! Here's how to get started:

1. Fork the repository
2. Create a feature branch (`git checkout -b my-feature`)
3. Make your changes
4. Run the tests (`swift test`)
5. Commit and push your branch
6. Open a pull request

## Guidelines

- All new functionality should include tests
- Keep the API surface small — propose new features in an issue first
- Run `swift build` and `swift test` before submitting

## Reporting Issues

Open an issue with a minimal reproduction case. Include your Swift version (`swift --version`) and platform.
