# Changelog

## 1.0.0

- Initial public release
- Core trie operations: `set`, `get`, `deleting`
- Traversal: `traverse` (array and string paths), `traverseChild`
- Query: `childKeys`, `childCharacters`, `allValues`, `childValues`, `valuesAlongPath`, `valuesExcludingPrefix`, `childPrefix`
- Merging: `merging(with:)`, `mergeAll(tries:)`
